PANDUAN MATERI.MD (MODUL 4):

1. DEFINISI
   - Sensor conditioning: prepare raw sensor signal untuk control logic
   - Filtering: reduce noise tanpa delay terlalu besar
   - Fusion: combine multiple sensor untuk estimate yang lebih robust
   - Trade-off: filtering baik (less noise) vs control responsiveness (low latency)

2. KONSEP INTI
   - Noise source: thermal (Johnson noise), electromagnetic interference (EMI), quantization (ADC)
   - Noise characteristic: white noise (flat spectrum), 1/f noise (low freq), impulse (spike)
   - Sampling theorem: sampling rate minimum 2× highest frequency (Nyquist)
   - Filter type: FIR (finite impulse response, no feedback), IIR (infinite, dengan feedback)
   - Moving average: simple, latency = window_size × sample_time
   - Low-pass filter: RC (analog), digital simulation (exponential moving average)
   - Complementary filter: encoder (low drift, high noise) + accelerometer (low noise, drift)
   - Kalman filter: optimal filter untuk linear system (predict → measure → update cycle)
   - Redundancy: 2-out-of-3 voting (2 agree → use value, 1 outlier → discard)

3. DIAGRAM & ILUSTRASI
   - Sensor signal before/after filter (time-domain waveform)
   - Frequency spectrum (FFT) before/after filter
   - Filter frequency response (Bode plot: gain vs frequency)
   - Complementary filter block diagram (encoder path + accel path + weight)
   - Kalman filter state transition diagram (predict → observe → update)
   - Sensor fusion architecture (3 sensor → voting logic → best estimate)
   - Phase lag example (filter delay effect pada control)

4. CONTOH KASUS INDUSTRI
   - Robot arm: encoder noisy → complementary filter dengan accel → smooth position
   - AGV: LiDAR + wheel encoder fusion untuk localization (SLAM)
   - Drone: gyroscope + accelerometer fusion untuk stable attitude estimation
   - CNC machine: position sensor voting untuk safety-critical application

5. RINGKASAN
   - Sensor bisa error, filtering & fusion essential
   - Trade-off filter delay vs noise reduction, tune sesuai requirement
   - Kalman filter powerful tapi kompleks, start dengan simple filter dulu

6. DESKRIPSI TUGAS VIDEO (MODUL 4)

   - Troubleshooting: filter parameter tuning, sensor not responding

     buffer_idx = (buffer_idx + 1) % WINDOW_SIZE;

   PERCOBAAN 5: KALMAN FILTER BASIC
   Tujuan: Optimal filter untuk 1D motion (position tracking)
   
   Langkah:
   a. Setup Kalman filter untuk 1D: state = [position, velocity]
   b. Motion model: x[k+1] = A × x[k] + w_noise (where A = [[1, dt], [0, 1]])
   c. Measurement model: z[k] = H × x[k] + v_noise (where H = [1, 0])
   d. Tuning: process noise (Q), measurement noise (R)
   e. Implement state transition (predict) & measurement update
   
   Predict step:
   x_pred = A × x_prev
   P_pred = A × P_prev × A^T + Q
   
   Update step:
   K = P_pred × H^T / (H × P_pred × H^T + R)  // Kalman gain
   x_new = x_pred + K × (z - H × x_pred)
   P_new = (I - K × H) × P_pred

PANDUAN MATERI.MD (MODUL 5):

1. DEFINISI
   - Actuator: device yang convert electrical signal menjadi mechanical motion
   - Motor: rotating actuator (linear actuator alternative)
   - Drive: circuit yang amplify control signal untuk power motor

2. KONSEP INTI
   - DC motor: simple, V_in → RPM (roughly linear), aber perlu brushing
   - BLDC: efficient, brushless, perlu commutation (driver kompleks)
   - Stepper: precise positioning, holding torque, low speed
   - Servo: built-in feedback + control, high precision, expensive
   - Motor constant: Kt (torque constant), Ke (back-EMF constant)
   - Power: P = T × ω = V × I
   - Efficiency: output power / input power (η = T × ω / V × I)
   - Thermal limitation: motor heat dissipation capacity
   - Mechanical constraint: gear ratio, friction, inertia

3. DIAGRAM & ILUSTRASI
   - Motor type comparison table (speed, torque, complexity, cost)
   - Motor equivalent circuit (R, L, back-EMF)
   - H-bridge circuit untuk DC motor
   - BLDC commutation sequence (6-step atau FOC)
   - Stepper motor coil sequence (full-step, half-step)
   - Torque-speed curve (rated vs peak torque)
   - Driver selection diagram (flowchart: motor type → driver type)
   - Current-time saat motor start (inrush current)

4. CONTOH KASUS INDUSTRI
   - Robot arm joint: servo motor untuk precision, atau BLDC dengan encoder & PID
   - AGV drive: 2× BLDC motor untuk traction, ESC untuk control
   - CNC spindle: 3-phase AC atau DC motor untuk high speed
   - Conveyor: DC motor atau 3-phase untuk continuous operation

5. RINGKASAN
   - Motor selection tergantung requirement: speed, torque, precision, cost
   - Driver design critical untuk reliable operation
   - Feedback essential untuk stable closed-loop control

6. DESKRIPSI TUGAS VIDEO (MODUL 5)

PANDUAN MATERI.MD (MODUL 6):

1. DEFINISI
   - Control loop: measure error (setpoint - feedback) → compute output via PID
   - Stability: oscillation damped, not unstable diverge
   - Performance: rise time (fast), overshoot (small), settling time (short), accuracy (steady-state error = 0)

2. KONSEP INTI
   - Proportional (P): error × Kp → output, fast response but overshoot & steady-state error
   - Integral (I): ∫error dt × Ki → output, eliminate steady-state error but slow down system
   - Derivative (D): d(error)/dt × Kd → output, damp overshoot & improve stability
   - Combined PID: output = Kp×error + Ki×∫error + Kd×d(error)/dt
   - Tuning: increase Kp → faster, decrease lag, increase overshoot
   - Increase Ki → eliminate steady-state error, but risk oscillation
   - Increase Kd → reduce overshoot, improve stability, but amplify noise
   - Anti-windup: clamp integral term when saturate, prevent integrator wind-up
   - Feedforward: add known compensation (e.g., gravity for vertical axis)
   - Bode plot: show frequency response, stability margin (phase margin > 30°)

3. DIAGRAM & ILUSTRASI
   - Block diagram PID control loop
   - Step response: ideal vs overdamped vs underdamped vs oscillatory
   - Bode plot: magnitude & phase vs frequency (showing stability margin)
   - Kp effect: increase Kp → lower peak, faster rise, higher overshoot
   - Ki effect: increase Ki → eliminate steady-state error, slower response
   - Kd effect: increase Kd → reduce overshoot, faster settling
   - Anti-windup illustration: integral term clamped at output limit
   - Feedforward compensation diagram: reference + error × PID + feedforward

4. CONTOH KASUS INDUSTRI
   - Robot arm joint position control: PID untuk trajectory tracking
   - Motor speed regulation: PID to maintain constant RPM despite load
   - Temperature control: PID untuk heater on/off
   - Quadrotor altitude control: cascaded PID (outer position, inner velocity)

5. RINGKASAN
   - PID adalah fundamental control algorithm, widely used industri
   - Tuning challenge: balance antara speed, accuracy, stability
   - Anti-windup & derivative filter essential untuk robust real-world implementation

6. DESKRIPSI TUGAS VIDEO (MODUL 6)

   - PID loop: feedback → error → P/I/D term → output

   Tujuan: Implement simple PID, test P/I/D effect independently

      - Read feedback (encoder)
      - Compute error = setpoint - feedback
      - PID computation (separate P, I, D term)
      - Output (PWM to motor)
   
   b. Implement P-only control: output = Kp × error, test step response
   c. Implement PI control: add integral term, test steady-state error
   d. Implement PID control: add derivative term, test overshoot damping
   
   Code skeleton:
   ```cpp
   struct PID {
     float Kp, Ki, Kd;
     float error_prev = 0;
     float integral = 0;
     
     float compute(float setpoint, float feedback, float dt) {
       float error = setpoint - feedback;
       float p_term = Kp * error;
       integral += error * dt;
       float i_term = Ki * integral;
       float d_term = Kd * (error - error_prev) / dt;
       error_prev = error;
       return p_term + i_term + d_term;
     }
   };
   ```
