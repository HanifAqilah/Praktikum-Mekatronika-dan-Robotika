# PROJECT MODUL 9: TRAJECTORY PLANNING & OPTIMIZATION FOR ROBOT MOTION

## 1. DESKRIPSI
Bangun trajectory planner lengkap untuk robot dengan dukungan trapezoidal dan S-curve profile, serta path interpolation (linear, circular, multi-point).

---

## 2. SPESIFIKASI
- Trapezoidal profile dengan validasi constraint.
- S-curve profile dengan jerk limit.
- Linear & circular path interpolation.
- Multi-point waypoint dengan blending.
- Estimasi waktu eksekusi dan smoothness.

---

## 3. DELIVERABLE
1. Arsitektur trajectory planner.
2. Implementasi trapezoidal & S-curve.
3. Implementasi linear & circular interpolation.
4. Multi-point waypoint planner.
5. Plot posisi/kecepatan/jerk.
6. Laporan perbandingan smoothness.
7. Demo video eksekusi trajectory.

---

## 4. KRITERIA PENILAIAN
- Profil memenuhi constraint.
- Jalur sesuai target.
- Smoothness (jerk rendah).
- Dokumentasi dan visualisasi jelas.
