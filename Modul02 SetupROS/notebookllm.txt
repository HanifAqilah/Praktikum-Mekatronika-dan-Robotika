slide 5 (Pendahuluan Robotika dan ROS 2)
Robotika adalah cabang teknik robot. ROS 2 adalah framework middleware untuk pengembangan perangkat lunak robotika. Menggunakan DDS untuk komunikasi real-time. Versi yang digunakan: Humble Hawksbill di Ubuntu 22.04.

slide 6 (Sistem Operasi Ubuntu untuk Robotika)
Ubuntu 22.04 LTS digunakan karena dukungan resmi ROS 2. Spesifikasi minimum: RAM 8GB, Storage 50GB. Ubuntu menyediakan kernel stabil untuk real-time applications. Kompatibel dengan ROS packages dan Gazebo simulation.

slide 7 (Arsitektur ROS 2 dan DDS)
ROS 2 menggunakan DDS middleware. Graph abstraction: Nodes, Topics, Services, Actions. Komunikasi terdesentralisasi tanpa master. Quality of Service (QoS) configurable. Real-time capable dan modular system.

slide 8 (Konsep Dasar ROS 2 Nodes dan Topics)
Node adalah entitas komputasi. Topic adalah saluran komunikasi asinkron. Perintah: ros2 node list, ros2 topic list, ros2 topic echo. Frequency (Hz) = 1 / period (s). Komunikasi publikasi-subscripsi antar nodes.

slide 9 (Services dan Actions ROS 2)
Services menggunakan pola request-response sinkron. Actions untuk tugas long-running dengan feedback. Perintah: ros2 service list, ros2 action list. Memungkinkan interaksi kompleks antar komponen robot secara terstruktur.

slide 10 (Kinematika Robot Maju dan Mundur)
Forward Kinematics: x = l1*cos(θ1) + l2*cos(θ1+θ2). Inverse Kinematics: θ2 = arccos((x²+y²-l1²-l2²)/(2*l1*l2)). Menghitung posisi end-effector dari joint angles dan sebaliknya untuk robot manipulator.

slide 11 (Denavit-Hartenberg Parameters)
Metode sistematis untuk kinematika robot. Empat parameter: θ (rotasi z), d (translasi z), a (translasi x), α (rotasi x). Transformasi matrix 4x4 menghubungkan frame tiap joint dalam robot arm secara berurutan.

slide 12 (Transformasi Koordinat dan TF2)
Rotasi menggunakan matrix R_x, R_y, R_z. Quaternion: q = w + xi + yj + zk. Menghindari gimbal lock. Transform matrix: kombinasi rotasi 3x3 dan translasi 3x1. TF2 library mengelola transformasi antar frame.

slide 13 (Kontrol Robot PID Controller)
Persamaan PID: u(t) = Kp*e(t) + Ki*∫e(t)dt + Kd*de(t)/dt. Kp proporsional, Ki integral, Kd derivatif. Tuning Ziegler-Nichols: Ku (ultimate gain) dan Tu (period oscillasi). Essential untuk kontrol motor robot.

slide 14 (Computer Vision OpenCV dan YOLO)
OpenCV untuk image processing: acquisition, preprocessing, feature extraction. YOLO real-time object detection. Output: [x_center, y_center, width, height, confidence]. IoU = Area_Intersection / Area_Union untuk Non-Maximum Suppression.

slide 15 (SLAM dan Navigasi)
SLAM membangun map sambil melacak posisi. Extended Kalman Filter: Prediction μ̄ = g(u,μ), Correction dengan Kalman gain K. Odometry differential drive: Δx = (Δs_left+Δs_right)/2*cos(θ). A* path planning: f(n)=g(n)+h(n).

slide 16 (Gazebo Simulation dan URDF)
Gazebo physics engine: F=m*a, τ=I*α. URDF format XML untuk deskripsi robot. Xacro macro language untuk fleksibilitas. Link, joint, visual, collision, inertial. Plugin untuk sensor dan aktuator di simulasi Gazebo.

slide 17 (MoveIt Motion Planning)
Pipeline: Robot State → Goal State → Planning Scene → Planner → Trajectory. RRT algoritma sampling-based. RRT-Connect: start node, random sample, extend, check collision. OMPL library menyediakan berbagai algoritma planning untuk robot arm.

slide 18 (Machine Learning dalam Robotika)
Reinforcement Learning dengan Q-Learning: Q(s,a) = Q(s,a) + α[r + γ*max_a'Q(s',a') - Q(s,a)]. Deep Q-Network menggunakan neural network. Robot belajar melalui interaction dengan environment untuk tugas kompleks.

slide 25 (Setup Repository ROS 2 Humble)
Langkah 5: Tambahkan universe repository. Download ROS key dan tambahkan repository ROS 2. Update apt packages. Install ros-humble-desktop, python3-colcon-common-extensions, python3-rosdep. Initialize rosdep dan update.

slide 26 (Instalasi ROS 2 Humble Desktop)
Lanjutan: echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc. Verifikasi dengan ros2 --version. Cek environment: printenv | grep ROS. Pastikan ROS_DISTRO=humble. ROS 2 siap digunakan untuk praktikum lanjutan.

slide 27 (Instalasi Machine Learning Libraries)
Langkah 6: Install python3-numpy, scipy, pandas, sklearn, matplotlib, seaborn. Install pip3 dan jupyter notebook. Library ML untuk pengolahan data sensor robot dan implementasi algoritma pembelajaran mesin dalam robotika nantinya.

slide 28 (Instalasi OpenCV dan YOLO)
Lanjut: sudo apt install python3-opencv, ros-humble-cv-bridge, ros-humble-image-transport. Pip install ultralytics untuk YOLO. Computer vision siap digunakan untuk deteksi objek real-time dengan kamera robot.

slide 29 (Instalasi Filter Libraries)
Lanjut: sudo apt install ros-humble-filters, ros-humble-laser-filters, ros-humble-robot-localization. Filter untuk pemrosesan data sensor LIDAR dan IMU. Menghilangkan noise dan meningkatkan akurasi data sensor robot.

slide 30 (Instalasi Kinematika Libraries)
Lanjut: sudo apt install ros-humble-orocos-kdl, ros-humble-kdl-parser, ros-humble-tf2-kdl. KDL untuk perhitungan kinematika dan dinamika robot. TF2 untuk transformasi koordinat antar frame robot.

slide 31 (Instalasi Controller Libraries)
Lanjut: sudo apt install ros-humble-ros2-control, ros-humble-ros2-controllers, ros-humble-control-toolbox. Framework untuk kontroler robot. Mendukung berbagai jenis kontroler: position, velocity, effort controllers untuk motor.

slide 32 (Instalasi MoveIt Motion Planning)
Lanjut: sudo apt install ros-humble-moveit. MoveIt untuk motion planning robot arm. Menyediakan algoritma RRT, PRM, OMPL. Visualisasi di RViz. Merencanakan gerakan end-effector ke target pose dengan obstacle avoidance.

Lanjut: sudo apt install ros-humble-urdf, ros-humble-xacro, ros-humble-joint-state-publisher, ros-humble-rviz2. Tools untuk deskripsi robot arm. RViz untuk visualisasi robot. Joint state publisher untuk mengontrol sudut tiap joint.
