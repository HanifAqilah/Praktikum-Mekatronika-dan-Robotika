# TUGAS VIDEO MODUL 06: BUILD DAN PROGRAM ROBOT LINE FOLLOWER

**Program Studi:** Teknologi Rekayasa Otomasi  
**Mata Kuliah:** Praktikum Mekatronika dan Robotika  
**Modul:** 06 – Build Line Follower  
**Sifat Tugas:** Individual  
**Durasi Video:** 15–25 menit  
**Format:** MP4 (minimal 720p)

---

## A. KETENTUAN UMUM

1. Video **per orang**, bukan per kelompok.
2. **Nama dan NIM** di awal video.
3. **Screen recording** untuk coding dan Serial Monitor.
4. **Webcam** terlihat di sudut layar saat menjelaskan.
5. **Video hardware wajib**: robot fisik berjalan di arena garis.

---

## B. URUTAN WAJIB ISI VIDEO

### BAGIAN 1 — PENJELASAN MATERI (Maks. 3 menit)
- [ ] Jelaskan prinsip kerja sensor IR reflektif
- [ ] Jelaskan shift register 74HC165 dan multiplexing
- [ ] Jelaskan H-Bridge L293D dan PWM motor control
- [ ] Jelaskan teori PID dan rumusnya

### BAGIAN 2 — DEMONSTRASI SELURUH PERCOBAAN (Maks. 8 menit)
- [ ] **Percobaan 1:** Assembly robot — tunjukkan proses perakitan
- [ ] **Percobaan 2:** Pembacaan sensor — tunjukkan Serial Monitor 12 sensor
- [ ] **Percobaan 3:** Test motor — video robot maju, mundur, belok
- [ ] **Percobaan 4:** Line following bang-bang — video robot mengikuti garis
- [ ] **Percobaan 5:** Line following PID — video robot lebih halus dari bang-bang
- [ ] **Percobaan 6:** Tuning PID — tunjukkan proses dan tabel tuning
- [ ] **Percobaan 7:** Fitur lanjutan (kalibrasi, adaptive speed, OLED)

### BAGIAN 3 — DEMONSTRASI PROJECT (Maks. 7 menit)
- [ ] Tunjukkan robot melewati tikungan 90° dan gap
- [ ] Tunjukkan perbandingan kecepatan fixed vs adaptive
- [ ] Tunjukkan telemetri WiFi (jika ada)
- [ ] Tunjukkan 1 full run terbaik di arena

### BAGIAN 4 — VIDEO HARDWARE (Maks. 5 menit)
- [ ] Tunjukkan robot dari 4 sudut pandang
- [ ] Tunjukkan detail PCB Main dan PCB Sensor terpasang
- [ ] Video robot berjalan mengikuti garis (minimal 1 putaran penuh)
- [ ] Tunjukkan perbandingan bang-bang vs PID secara fisik

### BAGIAN 5 — PENUTUP (Maks. 2 menit)
- [ ] Ringkasan dan kesimpulan
- [ ] Kendala dan solusi
- [ ] Parameter PID final yang digunakan
