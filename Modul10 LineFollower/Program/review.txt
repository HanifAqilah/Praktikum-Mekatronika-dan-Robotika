1. RINGKASAN UMUM
================================================================================

Program ini adalah kumpulan kode untuk praktikum mekatronika dan robotika
menggunakan ESP32 S2 Mini. Terdiri dari 6 modul utama:
- 01LcdI2c: Test OLED I2C display
- 02PushButton: Test input button dengan debouncing
- 03Motor: Test kontrol motor DC dengan PWM
- 04Sensor: Kalibrasi sensor IR dan threshold
- 05PID: (Tidak ditemukan di direktori)
- 06PathPlanning: Path planning dengan waypoint navigation

================================================================================
2. STRUKTUR KODE
================================================================================

+ Baik:
  - Kode terstruktur dengan baik per modul (01-06)
  - Penggunaan config.h sebagai centralized configuration
  - Dokumentasi kode sangat lengkap (comment header setiap file)
  - Pemisahan antara konfigurasi dan implementasi

- Masalah:
  - Modul 05PID tidak ditemukan di direktori (disebut di README)
  - Duplikasi kode eeprom_config.h (ada di root dan 04Sensor/src/)
  - Duplikasi implementasi fungsi EEPROM (eeprom_config.h vs eeprom_config.cpp)
  - Tidak ada library bersama (lib/) seperti yang disebut di README

================================================================================
4. ISSUES DAN BUGS
================================================================================

ISSUE #1: Typo PlatformIO Platform (CRITICAL)
-------------------------------------------------
File: Semua platformio.ini
Line: platform = espressif32

Status: KEMUNGKINAN TYPO
Detail: PlatformIO menggunakan "espressif32" untuk ESP32. Jika ini typo 
        ("espressif32"), build mungkin gagal atau menggunakan platform yang salah.
        
Fix: Pastikan "platform = espressif32" (bukan espressif32)

ISSUE #2: Duplikasi eeprom_config.h (HIGH)
-------------------------------------------------
File: /Program/eeprom_config.h vs /Program/04Sensor/src/eeprom_config.h

Status: DUPLIKASI BERBAHAYA
Detail: Dua file dengan nama sama tapi struktur dan implementasi berbeda.
        - Magic number berbeda (0xAB vs 0xABCD)
        - Struktur config berbeda
        - Implementasi fungsi diduplikasi
        
Fix: Gunakan satu sumber kebenaran (single source of truth). 
     Hapus duplikasi, pindahkan ke lib/.

ISSUE #3: Konflik Struct PathPoint (HIGH)
-------------------------------------------------
File: config.h line 148 vs 06PathPlanning/src/main.cpp line 227

Status: KONFLIK TIPE DATA
Detail: Dua definisi PathPoint yang berbeda. 06PathPlanning mendefinisikan
        PATH_PLANNING_ADVANCED yang menyebabkan PathPoint di config.h di-skip,
        tapi ini berisiko konflik include.

Fix: Standardisasi PathPoint struct, gunakan conditional compilation dengan benar.

ISSUE #4: Pin Motor Comment Salah (MEDIUM)
-------------------------------------------------
File: 03Motor/src/main.cpp line 44-48

Status: DOKUMENTASI SALAH
Detail: Komentar menyebut GPIO 16/17/18/19, padahal config.h menggunakan
        GPIO 11/10/9/8/7/6.

Fix: Perbaiki komentar sesuai config.h yang sebenarnya.

ISSUE #5: Global Variable di Header (MEDIUM)
-------------------------------------------------
File: config.h line 166: static int8_t lastPos = 0;

Status: BAD PRACTICE
Detail: Mendefinisikan variabel global di header file bisa menyebabkan
        multiple definition jika diinclude di beberapa translation unit.

Fix: Gunakan 'extern' declaration di header, define di satu .cpp file.

ISSUE #6: blocking delay() di performAction() (MEDIUM)
-------------------------------------------------
File: 06PathPlanning/src/main.cpp line 796, 800, 804, 812

Status: BLOCKING CODE
Detail: Penggunaan delay(800), delay(500), delay(1000) akan membuat
        robot tidak bisa merespons interrupt/tombol selama aksi berlangsung.

Fix: Implementasi non-blocking delay dengan millis().

ISSUE #7: Sensor Pin Conflik (LOW)
-------------------------------------------------
File: config.h line 105-108

Status: POTENSI KONFLIK
Detail: GPIO 16/17/18 digunakan untuk sensor, padahal bisa jadi strapping
        pins atau konflik dengan fungsi lain di ESP32 S2.

Fix: Cek datasheet ESP32 S2 Mini, pastikan pin tidak konflik.

ISSUE #8: Modul 05PID Hilang (INFO)
-------------------------------------------------
File: README.md menyebutkan 05PID, tapi tidak ada di direktori

Status: MISSING FILE
Detail: Modul tersulit (PID) tidak ada, padahal di README durations 80 menit.

Fix: Buat modul 05PID atau update README.
