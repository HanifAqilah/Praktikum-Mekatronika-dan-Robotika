PROMPT PRAKTIKUM MEKATRONIKA DAN ROBOTIKA - END-TO-END ROBOTICS/IIoT SYSTEM

==============================================================================
ARSITEKTUR SISTEM TERINTEGRASI
==============================================================================

Layer A — Plant/Robot (Mekanik + Elektronik)
- Mekanik: chassis AGV / arm 3-DOF / conveyor mini, transmisi (belt/gear/screw), backlash & rigiditas
- Elektronik: power tree (24V/12V/5V), driver motor, proteksi (fuse/TVS), E-Stop & interlock

Layer B — Real-time Control (Embedded)
- ESP32 untuk loop cepat: pembacaan sensor, PWM/FOC/stepper pulse, PID kecepatan/posisi, watchdog, fault handling
- Komunikasi: MQTT / Modbus RTU / CAN

Layer C — Edge Compute (Ubuntu Mini PC + ROS2 Humble)
- ROS2 sebagai "otak sistem": state machine, path planning, TF/URDF, sensor fusion level tinggi
- Bridge ke perangkat: micro-ROS atau MQTT bridge (ESP32 ↔ ROS2)

Layer D — Otomasi Industri (PLC + SCADA) - jika ada
- PLC: sequencing, safety logic level proses, handshake start/stop/mode, interlock
- SCADA: monitoring, alarm, trend, historian

Layer E — Webserver IoT
- API (REST) + WebSocket untuk dashboard
- Time-series DB (InfluxDB/Timescale) + Grafana/ThingsBoard
- Monitoring dan kontrol jarak jauh

VARIABEL YANG BISA DIUBAH (di bagian atas code):
// ===== CONFIGURATION - UBAH PARAMETER DI SINI =====
// Pin Assignment
#define MOTOR_PWM_PIN    25
#define ENCODER_A_PIN    26
#define ENCODER_B_PIN    27

// PID Parameters
float Kp = 2.0;   // Proportional gain - UBAH untuk melihat pengaruh terhadap rise time
float Ki = 0.5;   // Integral gain - UBAH untuk eliminasi steady-state error
float Kd = 0.1;   // Derivative gain - UBAH untuk mengurangi overshoot

// Control Parameters
float setpoint = 100.0;  // Target RPM
float max_output = 255;  // Max PWM value
int sample_time_ms = 10; // Control loop period (ms)

// PENJELASAN PARAMETER:
// - Kp: semakin besar, response semakin cepat, tapi bisa overshoot
// - Ki: menghilangkan error steady-state, tapi bisa bikin oscillation
// - Kd: meredam overshoot, tapi sensitive terhadap noise
// - setpoint: target kecepatan motor (RPM)
