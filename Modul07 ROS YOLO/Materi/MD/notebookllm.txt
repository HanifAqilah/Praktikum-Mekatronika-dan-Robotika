slide 5 (Peta Konsep ROS YOLO)
Buat peta konsep runtut: citra digital menjadi dataset, dataset diberi bounding box, model CNN belajar fitur, YOLO mendeteksi class dan lokasi objek, hasil training menghasilkan file best.pt, lalu ROS 2 membaca kamera, menjalankan inferensi, menerbitkan topic, dan mendukung keputusan robotika.

slide 6 (Citra Digital)
Jelaskan citra digital sebagai matriks angka. Grayscale memiliki intensitas piksel 0 sampai 255, sedangkan RGB memiliki kanal R, G, B. Gambar 640 x 480 RGB berbentuk tensor 480 x 640 x 3. Sebelum masuk neural network, nilai piksel dinormalisasi dengan x_norm = x / 255.

slide 7 (Machine Learning dan Deep Learning)
Jelaskan machine learning sebagai proses mencari fungsi prediksi y_hat = f(x; theta). Training bertujuan menemukan parameter theta terbaik dengan meminimalkan loss. Deep learning memakai banyak lapisan nonlinier sehingga mampu mempelajari fitur kompleks dari gambar, objek, warna, bentuk, dan tekstur.

slide 8 (Neuron Buatan)
Terangkan neuron buatan: input dikalikan bobot, dijumlahkan dengan bias, lalu masuk fungsi aktivasi. Rumus utama z = w^T x + b dan a = phi(z). Sebutkan aktivasi sigmoid, tanh, ReLU, Leaky ReLU, dan SiLU. Tekankan ReLU umum dipakai karena sederhana dan cepat.

slide 9 (MLP dan Backpropagation)
Jelaskan multilayer perceptron sebagai susunan layer yang memproses input menjadi prediksi. Untuk klasifikasi multi-kelas digunakan softmax dan cross entropy. Training memakai backpropagation dan gradient descent, yaitu pembaruan parameter theta mengikuti arah turunan loss agar kesalahan makin kecil.

slide 10 (Convolutional Neural Network)
Jelaskan CNN untuk data grid seperti gambar. Operasi konvolusi memakai kernel untuk mengekstraksi fitur tepi, tekstur, warna, bentuk, dan pola objek. Output dipengaruhi ukuran input, padding, kernel, dan stride. CNN menjadi dasar penting dalam object detection modern termasuk YOLO.

slide 11 (Feature Map dan Pooling)
Bahas feature map sebagai hasil aktivasi layer CNN. Layer awal menangkap tepi dan warna, layer tengah menangkap tekstur dan bentuk, layer akhir menangkap objek kompleks. Pooling mereduksi ukuran fitur, sedangkan batch normalization menstabilkan distribusi aktivasi dan mempercepat training.

slide 12 (Object Detection)
Jelaskan object detection menjawab dua hal: objek apa yang muncul dan di mana lokasinya. Output umum berisi class, confidence, x_min, y_min, x_max, y_max. Pada format YOLO, label ditulis class_id, x_center, y_center, width, height dan seluruh koordinat dinormalisasi terhadap ukuran gambar.

slide 13 (Bounding Box YOLO)
Tampilkan cara konversi bounding box piksel ke YOLO: x_center = ((x_min + x_max)/2)/W, y_center = ((y_min + y_max)/2)/H, width = (x_max - x_min)/W, height = (y_max - y_min)/H. Tekankan label harus tepat karena menjadi dasar model belajar lokasi objek.

slide 14 (IoU dan Evaluasi Deteksi)
Jelaskan Intersection over Union sebagai ukuran tumpang tindih box prediksi dan ground truth. Rumus IoU = area intersection / area union. IoU tinggi berarti lokasi prediksi baik. Threshold 0,5 umum dipakai untuk mAP50, sedangkan 0,5 sampai 0,95 lebih ketat seperti standar COCO.

slide 15 (Precision Recall mAP)
Bahas metrik evaluasi: True Positive adalah prediksi benar, False Positive adalah prediksi salah, False Negative adalah objek yang tidak terdeteksi. Precision = TP/(TP+FP), recall = TP/(TP+FN), F1 menyeimbangkan keduanya, AP adalah luas kurva precision-recall, dan mAP rata-rata AP semua kelas.

slide 16 (Prinsip YOLO)
Jelaskan YOLO, You Only Look Once, sebagai detektor satu tahap. Gambar diproses sekali untuk menghasilkan bounding box, confidence, dan class. Keunggulannya cepat, cocok untuk real-time robotika, pipeline sederhana, serta dapat dilatih ulang dengan dataset custom sesuai objek praktikum.

slide 17 (Evolusi dan Arsitektur YOLO)
Ringkas evolusi YOLO dari YOLOv1 berbasis grid, YOLOv2 memakai anchor, YOLOv3 multi-scale, YOLOv4 dengan optimasi akurasi, YOLOv5 berbasis PyTorch, hingga YOLOv8 yang mudah dipakai. Jelaskan arsitektur modern terdiri dari backbone, neck, dan head untuk prediksi akhir.

slide 18 (Multi-Scale dan Anchor-Free)
Jelaskan YOLO mendeteksi objek kecil, sedang, dan besar melalui feature map multi-scale, misalnya stride 8, 16, dan 32 pada input 640. YOLOv8 dikenal anchor-free, sehingga tidak perlu anchor prior eksplisit dan konfigurasi deteksi menjadi lebih sederhana untuk praktikum robotika.

slide 19 (Loss dan NMS)
Bahas loss YOLO sebagai gabungan kesalahan box, class, dan Distribution Focal Loss. Setelah prediksi, Non-Maximum Suppression memilih box terbaik dengan confidence tertinggi lalu menghapus box lain yang IoU-nya melewati threshold. Conf terlalu rendah memicu false positive, terlalu tinggi melewatkan objek.

slide 20 (Dataset YOLO)
Jelaskan struktur dataset YOLOv8: data.yaml, train/images, train/labels, valid/images, valid/labels, test/images, test/labels. File data.yaml berisi path, train, val, test, dan names. Setiap gambar memiliki file label txt berisi class_id serta koordinat bounding box ternormalisasi.

slide 21 (Split dan Variasi Dataset)
Jelaskan pembagian data umum train 70 persen, valid 20 persen, dan test 10 persen. Dataset baik harus bervariasi dalam jarak, sudut, pencahayaan, background, orientasi, dan kondisi objek tertutup sebagian. Rekomendasi praktikum minimal 50 sampai 100 gambar per kelas.

slide 22 (Anotasi dan Augmentasi)
Jelaskan anotasi dapat memakai Roboflow, CVAT, atau LabelStudio. Bounding box harus pas, tidak longgar, tidak sempit, label konsisten, dan direview. Augmentasi seperti flip, rotation, scale, brightness, blur, noise, mosaic, dan HSV membantu model tahan variasi tetapi tidak boleh merusak makna label.

slide 23 (Transfer Learning dan Training)
Jelaskan transfer learning memakai model pretrained seperti yolov8n.pt dari dataset besar lalu fine-tuning pada dataset custom. Keuntungannya butuh data lebih sedikit, training lebih cepat, dan akurasi awal lebih baik. Training YOLOv8 dapat dilakukan dengan Ultralytics CLI atau Python menggunakan data.yaml.

slide 24 (Evaluasi dan Inferensi)
Bahas evaluasi model dengan metrics.box.map50, metrics.box.map, precision, recall, loss, dan FPS. Overfitting tampak saat train loss turun tetapi val loss naik atau mAP stagnan. Inferensi dapat dilakukan pada gambar, folder validasi, webcam, atau frame kamera ROS dengan parameter conf dan iou.

slide 25 (ROS 2 dan YOLO)

slide 26 (OpenCV cv_bridge YOLO)
