# PROJECT MODUL 13: WEBSERVER IoT & DASHBOARD

## 1. DESKRIPSI
Bangun web server IoT untuk robot yang menyediakan REST API, WebSocket, database logging, dan dashboard monitoring.

---

## 2. SPESIFIKASI
- REST API minimal 10 endpoint.
- WebSocket untuk data sensor real-time.
- Database schema untuk log sensor & command.
- Dashboard dengan minimal 3 panel (status, grafik, kontrol).
- Authentication sederhana (API key).

---

## 3. DELIVERABLE
1. Source code backend (API + WebSocket).
2. Database schema & sample data.
3. Dashboard UI (HTML/CSS/JS).
4. Dokumentasi API (Swagger/OpenAPI).
5. Demo video.

---

## 4. KRITERIA PENILAIAN
- API stabil dan terdokumentasi.
- Dashboard responsif.
- Data logging berjalan.
- Security basic diterapkan.

---

## 5. MILESTONE
- Minggu 1: REST API.
- Minggu 2: Database + CRUD.
- Minggu 3: WebSocket + dashboard.
- Minggu 4: Integrasi & demo.
