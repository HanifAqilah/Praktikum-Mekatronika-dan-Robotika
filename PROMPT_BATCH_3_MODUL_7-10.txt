PANDUAN MATERI.MD (MODUL 7):

1. DEFINISI
   - Mekanisme: combination komponen mekanik untuk transmit motion & force
   - Transmisi: gear/belt/screw yang change speed, torque, direction
   - Backlash: unintended gap cause error saat direction change

2. KONSEP INTI
   - Gear ratio calculation: ratio = N_output / N_input (teeth ratio)
   - Spur gear: parallel axis, simple, noise at high speed
   - Planetary gear: compact, high ratio, smooth, complex
   - Belt & pulley: smooth, no backlash (with tensioner), power loss via slip
   - Lead screw: convert rotation → linear motion, high friction (need lubrication)
   - Backlash source: gear tooth gap, bearing play, bolt preload insufficient
   - Backlash effect: hysteresis in position, dead-zone saat direction change
   - Backlash compensation: measure hysteresis, add offset saat direction change
   - Workspace: set of reachable position (define by arm length, joint limit, singularity)
   - Dexterity: measure workspace quality (avoid singularity region)

3. DIAGRAM & ILUSTRASI
   - Gear type comparison (spur, planetary, bevel, worm)
   - Gear meshing diagram (pitch circle, backlash gap)
   - Backlash effect on position (before/after compensation)
   - Lead screw pitch & advance diagram
   - Belt & pulley system (tension, slip prevention)
   - Robot arm workspace (circular, rectangular, manipulability)
   - Singularity position (arm fully extend, or elbow = wrist)
   - Compliance diagram (force vs deformation)

4. CONTOH KASUS INDUSTRI
   - Robot arm: planetary gearbox untuk joint (compact, high reduction)
   - AGV: spur gear untuk wheel drive (simple, low cost)
   - CNC spindle: belt drive untuk smooth, adjustable speed
   - Servo robot: backlash < 1 arcmin (requirement), custom gear atau timing belt

5. RINGKASAN
   - Mekanisme design tradeoff: cost vs performance, simplicity vs precision
   - Backlash critical untuk control accuracy, must measure & compensate
   - Workspace & singularity important untuk robot reachability & safety

TUJUAN PEMBELAJARAN:

- Jacobian & velocity kinematics

KONSEP UTAMA:
1. Denavit-Hartenberg (DH) parameter: systematic notation untuk describe link & joint
2. Homogeneous transformation matrix: rotation (3×3 R) + translation (3×1 p)
3. Forward kinematics: compute end-effector position from joint angle
4. Inverse kinematics: solve joint angle given desired end-effector position
5. Analytical IK: closed-form solution (faster, not always exist)
6. Numerical IK: iterative solver (Jacobian transpose, damped least square, etc)
7. Jacobian matrix: relate joint velocity → end-effector velocity
8. Singularity: Jacobian lose rank, arm lose dexterity
9. Manipulability: measure workspace quality, avoid singularity

PANDUAN MATERI.MD (MODUL 8):

1. DEFINISI
   - Kinematics: study motion without force (geometry & time)
   - Forward kinematics: known joint angle → compute position
   - Inverse kinematics: desired position → compute joint angle

2. KONSEP INTI
   - DH parameter: link length (a), link twist (α), joint offset (d), joint angle (θ)
   - Transformation matrix: 4×4 matrix [R p; 0 1] (rotation + translation)
   - FK algorithm: T_0^n = T_0^1 × T_1^2 × ... × T_{n-1}^n
   - IK challenge: multiple solution (redundancy), no solution (unreachable), singularity
   - Analytical IK: solve algebraically, specific untuk robot type
   - Numerical IK: iterative approach, general but slow
   - Jacobian: ∂x/∂θ matrix (relate velocity)
   - Singularity: det(J) = 0, arm cannot move in certain direction

3. DIAGRAM & ILUSTRASI
   - Robot 3D model dengan joint & link label
   - DH parameter table illustration
   - FK process: step-by-step transformation matrix
   - IK solution geometrically (2-DOF arm, multiple IK solution)
   - Jacobian visualization (velocity mapping)
   - Workspace reachability map (2D heatmap, different color for different reachability)
   - Singularity position (arm fully extended, elbow = wrist)
   - Manipulability measure (ratio eigenvalue Jacobian)

4. CONTOH KASUS INDUSTRI
   - Robotic arm ABB IRB: 6-DOF, redundant, need numerical IK
   - SCARA robot: 4-DOF (3 rotation + 1 vertical), planar + Z movement
   - Delta robot: 3-DOF parallel kinematics, fast pick & place
   - Humanoid robot: complex kinematics, balance control

5. RINGKASAN
   - FK straightforward, IK challenging (multiple solution / no solution)
   - Singularity must avoid untuk maintain control authority
   - Numerical IK practical for complex robot, analytical faster for simple robot

   ```python
       # Return: position [x, y, z], orientation (rotation matrix)
       T = np.eye(4)
       for i, theta in enumerate(q):
           T_i = dh_to_matrix(DH_PARAMS[i], theta)
           T = T @ T_i
       return T[0:3, 3], T[0:3, 0:3]
   ```

   For 2-DOF (planar arm):

   Code (2-DOF):
   ```python
   def inverse_kinematics_2dof(x, y):
       # Analytical solution for 2-link planar arm
       L1, L2 = link_length[0], link_length[1]
       
       # Check reachability
       dist = np.sqrt(x**2 + y**2)
       if dist > L1 + L2 or dist < abs(L1 - L2):
           return None  # Unreachable
       
       # Solve using law of cosine
       cos_theta2 = (x**2 + y**2 - L1**2 - L2**2) / (2*L1*L2)
       theta2 = np.arccos(cos_theta2)  # Elbow-up solution
       
       theta1 = np.atan2(y, x) - np.atan2(L2*np.sin(theta2), L1 + L2*np.cos(theta2))
       
       return [theta1, theta2]
   ```

   - Plot manipulability w(q) = sqrt(det(J×J^T)) across workspace
   
   Code:

   ```python
   def jacobian(q):
       # Numerical Jacobian: ∂FK / ∂q
       epsilon = 1e-6
       J = np.zeros((3, len(q)))
       
       for i in range(len(q)):
           q_plus = q.copy()
           q_plus[i] += epsilon
           
           pos_plus, _ = forward_kinematics(q_plus)
           pos, _ = forward_kinematics(q)
           
           J[:, i] = (pos_plus - pos) / epsilon
       
       return J
   
   def singularity_check(q):
       J = jacobian(q)
       det = np.linalg.det(J[:3, :3])
       return abs(det) < 1e-6
   ```

PANDUAN MATERI.MD (MODUL 9):

1. DEFINISI
   - Trajectory: position, velocity, acceleration as function of time
   - Velocity profile: velocity scheduling (how velocity changes over time)
   - Path: geometric route (position only, no time info)

2. KONSEP INTI
   - Trapezoidal profile: 3 phase (accel at max accel → move at max velocity → decel at max accel)
   - Profile parameter: max velocity (vmax), max acceleration (amax), target distance (d)
   - Calculation: acceleration phase time ta = vmax/amax, distance da = 0.5 * amax * ta^2
   - S-curve profile: additional phase untuk smooth jerk (accel-accel → accel → decel-accel → decel)
   - Jerk: dA/dt (rate of acceleration change), high jerk cause vibration
   - Path interpolation: linear motion (straight line), circular (arc), cubic spline (smooth curve)
   - Velocity profile over path: can be trapezoidal or S-curve

3. DIAGRAM & ILUSTRASI
   - Trapezoidal velocity profile (time vs velocity graph)
   - S-curve velocity profile (smoother transition)
   - Position vs time (trapezoidal: curved-linear-curved)
   - Jerk profile (trapezoidal have step jerk, S-curve smooth)
   - Linear path interpolation (2D position vs time)
   - Circular arc interpolation (center, radius, angle, arc length)
   - Spline path (control point, smooth curve)
   - Robot motion: smooth vs jerky (visual comparison)

4. CONTOH KASUS INDUSTRI
   - Pick & place robot: smooth motion reduce shock, improve precision
   - CNC machining: feedrate planning critical untuk tool life
   - Humanoid robot walking: smooth trajectory important untuk balance
   - Car motion: smooth acceleration improve comfort & efficiency

5. RINGKASAN
   - Trapezoidal simple, S-curve smooth
   - Path planning (geometry) vs trajectory planning (+ timing) different concept
   - Smooth trajectory reduce vibration, improve accuracy, extend component life

   PERCOBAAN 1: TRAPEZOIDAL PROFILE CALCULATION
   - Input: start position (s0), target position (s), max velocity (vmax), max acceleration (amax)
   - Calculation:
     a. Time acceleration phase: ta = vmax / amax
     b. Distance acceleration: sa = 0.5 * amax * ta^2
     c. Constant velocity distance: sv = s - 2*sa
     d. Constant velocity time: tv = sv / vmax (if sv > 0)
     e. Deceleration time: td = ta (symmetric)
   - Output: table of (time, position, velocity, acceleration)
   
   Code template (Python):
   ```python
   def trapezoidal_profile(start, target, vmax, amax):
       distance = abs(target - start)
       
       # Acceleration phase
       ta = vmax / amax
       sa = 0.5 * amax * ta**2
       
       if 2*sa > distance:  # Cannot reach vmax
           # Triangular profile
           ta = np.sqrt(distance / amax)
           sa = distance / 2
           tv = 0
           td = ta
       else:
           # Trapezoidal profile
           sv = distance - 2*sa
           tv = sv / vmax
           td = ta
       
       # Generate trajectory
       trajectory = []
       # Phase 1: Acceleration (0 to ta)
       for t in np.linspace(0, ta, 100):
           s = 0.5 * amax * t**2
           v = amax * t
           trajectory.append((t, s, v, amax))
       # Phase 2: Constant velocity (ta to ta+tv)
       # ...
       # Phase 3: Deceleration (ta+tv to ta+tv+td)
       # ...
       
       return trajectory
   ```

   PERCOBAAN 3: LINEAR PATH INTERPOLATION
   - Point A (x1, y1) → Point B (x2, y2)
   - Linear interpolation: position(t) = A + (B-A) * t / T, t ∈ [0, T]
   - Apply trapezoidal profile untuk velocity
   - Result: smooth linear motion from A to B
   
   Code:
   ```python
   def linear_trajectory(start, target, duration, vmax, amax):
       # Generate time-parameterized path
       trajectory = []
       
       # Velocity profile (already computed)
       vel_profile = trapezoidal_profile(0, 1, vmax, amax)  # 0 to 1 (normalized)
       
       # Position interpolation
       direction = (np.array(target) - np.array(start)) / np.linalg.norm(np.array(target) - np.array(start))
       distance = np.linalg.norm(np.array(target) - np.array(start))
       
       for t, s, v, a in vel_profile:
           actual_position = np.array(start) + direction * s * distance
           trajectory.append((t, actual_position, v))
       
       return trajectory
   ```
