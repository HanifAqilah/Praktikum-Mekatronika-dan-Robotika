slide 2 (Outline Materi)
Buat slide outline materi berisi urutan bahasan: konsep PLC dan scan cycle, jaringan industri, Modbus TCP, coil dan register, computer vision, MediaPipe Hands, ROS 2 node, integrasi AI ke PLC, pengukuran delay, akurasi, troubleshooting, keselamatan, watchdog, heartbeat, dan fail-safe.

slide 3 (Outline Tugas)
Buat slide outline tugas: praktikan menjalankan sistem AI vision ke PLC, membuat video YouTube masing-masing, menampilkan identitas, teori, folder program, instalasi, setup Modbus, mapping jari, demo running, tabel uji, delay, akurasi, troubleshooting, kesimpulan. slide 4 (Capaian Pembelajaran)
Buat slide capaian pembelajaran: mahasiswa mampu menjelaskan PLC, scan cycle, I/O digital, coil, register, komunikasi industri, Modbus TCP, AI vision, MediaPipe, ROS 2 node, workspace, topic, parameter, serta mampu menghubungkan kamera, GUI, jaringan, PLC/V-BOX, dan output trainer.

slide 5 (Gambaran Sistem)
Buat slide gambaran sistem: tangan praktikan ditangkap kamera, citra diproses OpenCV dan MediaPipe Hands, status jari ditentukan Python, GUI menampilkan kondisi, ROS 2 node mengirim data melalui Modbus TCP ke PLC/V-BOX, lalu coil/register mengaktifkan LED atau output trainer.

slide 6 (Dasar PLC)
Buat slide dasar PLC: Programmable Logic Controller adalah komputer industri untuk membaca input, menjalankan logika kontrol, dan menghasilkan output deterministik. Jelaskan komponen CPU, power supply, input module, output module, memory, dan communication port untuk otomasi mesin.

slide 7 (Scan Cycle PLC)
Buat slide scan cycle PLC: PLC membaca input, mengeksekusi program ladder/ST/FBD, memperbarui output, lalu melakukan komunikasi dan diagnosis. Jelaskan respon dipengaruhi input filter, waktu scan, output delay, dan network delay. Contoh Tscan 10 ms menghasilkan fscan 100 Hz.

slide 8 (Data dan Logika PLC)
Buat slide jenis data PLC: X/I untuk input digital, Y/Q untuk output, M sebagai internal relay, T timer, C counter, D/R register, AI/AQ analog. Tambahkan logika boolean AND, OR, NOT, latch start-stop, timer ON delay, counter rising edge, dan scaling analog sensor.

slide 9 (Keselamatan PLC)
Buat slide keselamatan PLC: output berbahaya harus memakai interlock fisik, AI vision tidak boleh menjadi satu-satunya safety device, emergency stop harus hardwired, jaringan praktikum dipisah dari produksi, alamat coil divalidasi, dan hindari write register acak ke PLC produksi.

slide 10 (Jaringan Industri)
Buat slide jaringan industri: IP address IPv4, subnet mask, gateway, port, firewall, kabel, switch, dan konflik IP menentukan keberhasilan komunikasi. Jelaskan perangkat harus satu subnet atau memiliki routing benar. Tekankan port Modbus TCP standar 502 dan pengecekan ping.

slide 11 (Latency dan Throughput)
Buat slide latency sistem: total waktu kontrol dipengaruhi kamera, processing AI, ROS, TCP, dan PLC. Tampilkan rumus Ttotal = Tcamera + Tprocessing + Tros + Ttcp + Tplc. Jelaskan FPS kamera, waktu antar-frame, throughput data, dan contoh 30 FPS berarti 33,3 ms per frame.

slide 12 (Dasar Modbus TCP)
Buat slide Modbus TCP: protokol komunikasi industri client-server melalui Ethernet. Client mengirim request, PLC/server memberi response. Jelaskan model data coil 0xxxx, discrete input 1xxxx, input register 3xxxx, holding register 4xxxx, serta fungsi read/write data.

slide 13 (Function Code Modbus)
Buat slide function code: FC01 read coils, FC02 read discrete inputs, FC03 read holding registers, FC04 read input registers, FC05 write single coil, FC06 write single register, FC15 write multiple coils, FC16 write multiple registers. Jelaskan pemilihan fungsi sesuai area data.

slide 14 (Struktur dan Addressing Modbus)
Buat slide struktur Modbus TCP: MBAP header berisi transaction ID, protocol ID, length, unit ID, lalu PDU berisi function code dan data. Jelaskan banyak library memakai alamat berbasis 0, sehingga coil manual 00005 sering diprogram sebagai address 4.

slide 15 (Coil dan Register)
Buat slide coil dan register: coil bernilai 0 atau 1, write ON memakai 0xFF00 dan OFF 0x0000. Holding register menyimpan 16-bit 0 sampai 65535, bisa signed atau unsigned. Dua register dapat digabung menjadi 32-bit atau float IEEE 754 dengan aturan endian.

slide 16 (Exception Modbus)
Buat slide exception Modbus: bila error, function code response menjadi FC request + 0x80, misalnya FC03 menjadi 0x83. Jelaskan kode umum: illegal function, illegal data address, illegal data value, slave device failure. Kaitkan dengan troubleshooting alamat, nilai, dan server PLC.

slide 17 (Computer Vision)
Buat slide computer vision: citra digital adalah matriks piksel RGB, resolusi = width x height. Jelaskan konversi grayscale, normalisasi koordinat landmark 0 sampai 1, konversi ke piksel, jarak Euclidean, sudut antar vektor, serta pengaruh pencahayaan dan background.

slide 18 (Akurasi Deteksi)
Buat slide akurasi deteksi: jelaskan confusion matrix biner berisi TP, FP, TN, FN. Tampilkan rumus accuracy, precision, recall, dan F1-score secara ringkas. Hubungkan dengan uji gestur tangan: jumlah prediksi benar dibanding total percobaan untuk setiap jari dan kombinasi.

slide 19 (Smoothing Gestur)
Buat slide smoothing gestur: status jari dapat bergetar karena noise kamera dan landmark. Gunakan voting N frame, threshold stabil, moving average, atau exponential moving average. Jelaskan state bernilai 1 jika jumlah frame aktif melewati threshold sehingga output PLC tidak berkedip.

slide 20 (MediaPipe Hands)
Buat slide MediaPipe Hands: algoritma mendeteksi 21 landmark tangan, mulai wrist, thumb, index, middle, ring, hingga pinky. Deteksi jari terbuka dapat memakai perbandingan tip dan PIP. Untuk jari selain jempol, tip lebih tinggi dari PIP menandakan jari terbuka.

slide 21 (Dasar ROS 2)
Buat slide ROS 2: middleware robotika berbasis node. Node berkomunikasi melalui topic, service, action, parameter, dan transform. Pada modul ini node membaca kamera, memproses MediaPipe, menampilkan GUI, lalu menulis data ke PLC via Modbus TCP dari package mediapipe_modbus_pkg.

slide 22 (Workspace dan Eksekusi ROS 2)
Buat slide workspace ROS 2: struktur berisi src, build, install, dan log. Build package memakai colcon build --packages-select mediapipe_modbus_pkg, source install/setup.bash, lalu jalankan ros2 run mediapipe_modbus_pkg mediapipe_modbus_node. Tekankan source ROS 2 sebelum running.

slide 23 (Integrasi AI ke PLC)
Buat slide integrasi AI-PLC: status lima jari dinyatakan F=[f1,f2,f3,f4,f5], setiap fi bernilai 0 atau 1. Mapping sederhana Coil_i = fi. Jumlah jari terbuka Nopen = jumlah fi, sedangkan kode gestur 5-bit menghasilkan nilai 0 sampai 31 untuk perintah PLC.

slide 24 (State Machine Gestur)
Buat slide state machine gestur: alur IDLE, DETECT, VALIDATE, SEND_MODBUS, PLC_ACTION, MONITOR. Gestur dianggap valid jika confidence minimal terpenuhi dan stable frames cukup. Jelaskan validasi diperlukan agar perintah tidak terkirim akibat noise sesaat dari kamera.

slide 25 (Analisis Latensi)
Buat slide analisis latensi end-to-end: Te2e terdiri dari capture, preprocess, inference, GUI, Modbus, dan scan PLC. Contoh capture 33 ms, inference 20 ms, GUI 5 ms, Modbus 10 ms, PLC scan 10 ms menghasilkan total 78 ms. Tekankan pengukuran nyata dengan video.

slide 26 (Troubleshooting Materi)
Buat slide troubleshooting konsep: kamera gagal karena device salah atau dipakai aplikasi lain; MediaPipe error karena versi numpy/opencv; PLC tidak terkoneksi karena IP, subnet, kabel, port; coil tidak berubah karena offset alamat; deteksi tidak stabil karena cahaya buruk; delay besar karena FPS rendah.
