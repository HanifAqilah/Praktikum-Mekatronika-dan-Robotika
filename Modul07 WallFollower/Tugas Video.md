## A. KETENTUAN UMUM

1. Video **per orang**, bukan per kelompok.
2. **Nama dan NIM** di awal video.
3. **Screen recording** untuk coding dan Serial Monitor.
4. **Webcam** terlihat di sudut layar saat menjelaskan.
5. **Video hardware wajib**: robot fisik berjalan di labirin.

---

## B. URUTAN WAJIB ISI VIDEO

### BAGIAN 1 — PENJELASAN MATERI (Maks. 3 menit)
- [ ] Jelaskan prinsip kerja sensor ultrasonik HC-SR04
- [ ] Jelaskan konsep wall following dan P / PD control
- [ ] Jelaskan Finite State Machine (FSM) untuk navigasi labirin

### BAGIAN 2 — DEMONSTRASI SELURUH PERCOBAAN (Maks. 8 menit)
- [ ] **Percobaan 1:** Pemasangan sensor — tunjukkan mounting dan akurasi sensor
- [ ] **Percobaan 2:** Filter moving average — tunjukkan perbandingan data mentah vs filtered
- [ ] **Percobaan 3:** Wall following P-control — video robot mengikuti dinding lurus
- [ ] **Percobaan 4:** Wall following PD-control — video perbandingan P vs PD
- [ ] **Percobaan 5:** Obstacle avoidance — video robot menghindari rintangan
- [ ] **Percobaan 6:** FSM labirin — video robot menyelesaikan labirin
- [ ] **Percobaan 7:** Dual-mode line + wall — video mode switching

### BAGIAN 3 — DEMONSTRASI PROJECT (Maks. 7 menit)
- [ ] Tunjukkan robot menyelesaikan labirin start → finish
- [ ] Tunjukkan dead-end recovery
- [ ] Tunjukkan dual-mode (line → wall → line)
- [ ] Tunjukkan speed run terbaik

### BAGIAN 4 — VIDEO HARDWARE (Maks. 5 menit)
- [ ] Tunjukkan sensor HC-SR04 terpasang di robot (3 sensor)
- [ ] Tunjukkan labirin fisik
- [ ] Video robot bernavigasi dari atas (bird-eye view)
- [ ] Video close-up saat robot berbelok

### BAGIAN 5 — PENUTUP (Maks. 2 menit)
- [ ] Ringkasan dan kesimpulan
- [ ] Kendala dan solusi
- [ ] Parameter PD final
